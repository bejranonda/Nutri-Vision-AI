# 🥗 NutriVision AI - ผู้ช่วยโภชนาการอัจฉริยะ

> แอปพลิเคชันวิเคราะห์โภชนาการด้วย AI เฉพาะสำหรับอาหารไทย ช่วยให้คนไทยเลือกทานอาหารที่ดีต่อสุขภาพด้วยหลักวิทยาศาสตร์

## 🌟 ฟีเจอร์หลัก

### ความสามารถหลัก
- **🔍 สแกนอาหารด้วย AI**: ถ่ายรูปแล้วระบบจะบอกส่วนประกอบและโภชนาการทันที พร้อมแนะนำลำดับการกิน
- **🧪 วิเคราะห์ระบบเผาผลาญขั้นสูง**: ตรวจจับ **อาหารแปรรูปสูง (UPF)** และประเมินปริมาณ **ฟรุกโตส** (ภาระของตับ)
- **📊 คะแนนสุขภาพ 8 มิติ**: วิเคราะห์ครบทุกด้านของโภชนาการ:
  - 🩸 **ผลกระทบต่อน้ำตาล**: ใหม่! หักคะแนนฟรุกโตส และเพิ่มคะแนนตามอัตราส่วนใยอาหารต่อคาร์บ
  - 🏭 **ระดับการแปรรูป**: หักคะแนนหนักสำหรับ UPF และสารเติมแต่งอุตสาหกรรม
  - 🧬 **ดัชนีความอิ่ม (Satiety Index)**: ประเมินว่ามื้อนี้จะทำให้อิ่มนานแค่ไหน
- **👩‍🏫 มาสคอต "ชินนี่"**: เพื่อนซี้ AI ที่ยึดหลักปรัชญา **"อยู่เพื่อกินบำนาญ"** ของเธอเอง!
- **🚶‍♂️ กิจกรรมหลังมื้ออาหาร**: ระบบช่วยเตือนให้ **เดินเล่น 10-15 นาที** หลังมื้อใหญ่เพื่อลดน้ำตาลพุ่ง

- **🍜 เชี่ยวชาญอาหารไทย**:
  - สูตรอาหารไทยกว่า 1,000 สูตร พร้อมข้อมูลโภชนาการ
  - ฐานข้อมูลวัตถุดิบไทย
  - ความรู้ตามภูมิปัญญาไทย
  - แปลงหน่วยตวงไทย (ช้อนโต๊ะ, ถ้วย)

- **💬 ปรึกษาผู้เชี่ยวชาญ AI**:
  - สนทนากับนักโภชนาการ AI เป็นภาษาไทย
  - คำแนะนำตามหลักวิทยาศาสตร์
  - ปรับให้เหมาะกับเป้าหมายของคุณ

- **📱 PWA ใช้งานง่ายบนมือถือ**:
  - ติดตั้งเหมือนแอป ไม่ต้องผ่าน App Store
  - ใช้งานออฟไลน์ได้
  - เข้าถึงกล้องได้เร็ว

### ฟีเจอร์พิเศษสำหรับตลาดไทย
- **จัดการน้ำตาลในเลือด**: เหมาะกับคนไทยที่ทานข้าวเป็นหลัก
- **อร่อย ตาม ลำดับ (Food Sequencing)**: ผัก → โปรตีน → ไขมัน → คาร์โบไฮเดรต → ของหวาน (ลดน้ำตาลพุ่ง 70%)
  ```
  🥦 ผัก (Fiber) → 🍗 โปรตีน/ไขมัน → 🍚 คาร์โบไฮเดรต → 🍰 ของหวาน
     (ลำดับ 1)         (ลำดับ 2)           (ลำดับ 3)       (ลำดับ 4)
  ```
- **ปรัชญา "อยู่เพื่อกินบำนาญ"**: เน้นการกินให้อร่อยและมีสุขภาพดีเพื่อใช้ชีวิตวัยเกษียณอย่างมีความสุข
- **เข้าสู่ระบบด้วย Line**: รองรับแอปยอดนิยมของคนไทย
- **AI พูดภาษาไทย**: สนทนาธรรมชาติเป็นภาษาไทย

- **🌐 รองรับหลายภาษา**: รองรับภาษาไทย, อังกฤษ, เยอรมัน และเดนมาร์ค ผ่าน `next-intl`
- **☁️ Cloudflare Edge Deployment**: รันบน Cloudflare Workers (ผ่าน OpenNext), D1 และ Workers AI
- **⚡ ประสิทธิภาพสูง**: ปรับแต่ง SEO, การโหลดฟอนต์ และการประมวลผลบน Edge เพื่อประสบการณ์การใช้งานระดับโลก

## 🏗️ สถาปัตยกรรม (Architecture)

### Tech Stack

**Serverless Backend (TypeScript)**
- Next.js Edge APIs - ฟังก์ชันไร้เซิร์ฟเวอร์ประสิทธิภาพสูง
- Cloudflare D1 - ฐานข้อมูล SQLite บน Edge
- Cloudflare Workers AI - Llama 3 และโมเดลอื่นๆ สำหรับการสนทนา
- Drizzle ORM - จัดการฐานข้อมูลแบบ Type-safe

**Frontend (TypeScript)**
- Next.js 14 - React framework พร้อม App Router
- Tailwind CSS - สไตล์แบบ Glassmorphism
- next-intl - ระบบหลายภาษา (TH, EN, DE, DA)
- TanStack Query - จัดการสถานะฝั่งเซิร์ฟเวอร์
- Zustand - จัดการสถานะฝั่งไคลเอนต์
- Recharts - การแสดงผลข้อมูล

**โครงสร้างพื้นฐาน (Infrastructure)**
- Cloudflare Workers - โฮสติ้ง Frontend & API (ผ่าน OpenNext)
- Wrangler - เครื่องมือจัดการบริการ Cloudflare
- GitHub Actions - CI/CD

## 🚀 เริ่มต้นใช้งาน

### ข้อกำหนดเบื้องต้น
- Docker และ Docker Compose
- Git
- Google Gemini API key ([สมัครที่นี่](https://makersuite.google.com/app/apikey))

### ติดตั้ง

1. **โคลนโปรเจค**
```bash
git clone https://github.com/yourusername/Nutri-Vision-AI.git
cd Nutri-Vision-AI
```

2. **ตั้งค่า environment variables**
```bash
cp .env.example .env
```

แก้ไขไฟล์ `.env` และใส่ข้อมูลของคุณ:
```env
GEMINI_API_KEY=ใส่_api_key_ของคุณ_ที่นี่
SECRET_KEY=สุ่ม_secret_key  # สร้างด้วย: openssl rand -hex 32
JWT_SECRET_KEY=สุ่ม_jwt_secret
```

3. **เริ่มระบบ (ติดตั้งทั้งหมดอัตโนมัติ)**
```bash
chmod +x scripts/install-all.sh
./scripts/install-all.sh
```

4. **เข้าใช้งานแอป**
- หน้าเว็บ: http://localhost:3000
- Backend API: http://localhost:8000
- เอกสาร API: http://localhost:8000/docs

## 🎯 ระบบให้คะแนนโภชนาการ

ระบบให้คะแนน 8 มิติของเรา วิเคราะห์อาหารในหลายมุมมอง:

### 1. ผลกระทบต่อน้ำตาลในเลือด (0-100)
- คำนวณ Glycemic Load
- คำนึงถึงเส้นใยอาหาร
- สำคัญมากสำหรับอาหารไทยที่มีคาร์โบสูง
- **คะแนนสูง = น้ำตาลพุ่งน้อย**

### 2. สุขภาพลำไส้ (0-100)
- ปริมาณเส้นใย (ละลายน้ำ/ไม่ละลายน้ำ)
- สาร prebiotic และ probiotic
- คะแนนพิเศษสำหรับอาหารหมัก
- **คะแนนสูง = ลำไส้แข็งแรง**

### 3. การอักเสบ (0-100)
- อัตราส่วน Omega-3 ต่อ Omega-6
- ค่า antioxidant ORAC
- ส่วนประกอบต้านการอักเสบ
- **คะแนนสูง = ลดการอักเสบ**

### 4. ความหนาแน่นของสารอาหาร (0-100)
- สารอาหารต่อแคลอรี่ (ANDI score)
- ความหนาแน่นของโปรตีนและเส้นใย
- ความอุดมสมบูรณ์ของวิตามิน/แร่ธาตุ
- **คะแนนสูง = สารอาหารเยอะต่อแคลอรี่**

### 5. ระดับการแปรรูป (0-100)
- จำแนกตาม NOVA (1-4)
- ตรวจจับสารเติมแต่ง
- เปอร์เซ็นต์ของอาหารสด
- **คะแนนสูง = แปรรูปน้อย**

### 6. คุณภาพโปรตีน (0-100)
- กรดอะมิโนครบถ้วน
- ปริมาณโปรตีน
- คุณภาพของแหล่งโปรตีน (PDCAAS)
- **คะแนนสูง = โปรตีนดีกว่า**

### 7. วิตามินและแร่ธาตุ (0-100)
- % ความต้องการต่อวันของวิตามิน/แร่ธาตุ 12 ชนิด
- ความหลากหลายของสารอาหาร
- ปัจจัยการดูดซึม
- **คะแนนสูง = โภชนาการครบถ้วน**

### 8. คะแนนสุขภาพรวม (0-100)
- ค่าเฉลี่ยถ่วงน้ำหนักของทุกมิติ
- ปรับตามเป้าหมายของผู้ใช้
- ปรับตามบริบทอาหารไทย
- **คะแนนสูง = ดีต่อสุขภาพโดยรวม**
